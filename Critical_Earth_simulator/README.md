# 미니 지구 모델 — 학생용 실행 가이드

CO₂ 배출이 대기·기온·바다(pH·포화도 Ω)를 어떻게 바꾸는지 3D 미니 지구로 살펴보는 프로그램입니다.

## 받기 — `MiniEarth.html` 한 파일

[**→ Releases 페이지에서 다운로드**](https://github.com/ChealminE/mini-earth-sim-solo/releases/latest)

파일 하나를 **더블클릭**하면 브라우저에서 바로 열립니다. 설치·인터넷이 필요 없고, 카톡·메일·USB로 옮겨도 그대로 열립니다(윈도우·맥 모두).
태블릿에서는 그래프 화면만 됩니다 — 1인칭 탐험은 키보드·마우스 전용입니다(아래 문제 해결).

> 아두이노·ESP32 센서를 쓰는 **직접 실험**이 들어 있던 협동판은 태그 [`v2.0-collab-final`](https://github.com/ChealminE/mini-earth-sim/releases/tag/v2.0-collab-final)에 있습니다. 이 단독판에는 센서 기능이 없습니다.

시작 화면에서 보고 싶은 걸 고르세요.

| 화면 | 내용 |
|---|---|
| **현재 실태** | 관측 자료 — 대기 CO₂(NOAA 지구 평균, 1979~), 기온 편차(HadCRUT5, 1850~1900 기준, 1850~), 해양 pH(HOT Station ALOHA, 1989~), 화석연료 배출(GCP). 숫자·그래프 옆 ⓘ에 출처 |
| **미래 예측** | 1750~2200년 타임라인(연평균). 2023년까지는 관측(빗금 왼쪽), 그 뒤는 예측 — ▶ 재생하거나 연도 막대를 미래로 끌면 예측선이 그려진다. 그래프 4개(대기 CO₂·기온 편차·해수 pH·해수온)에 재생 위치의 값이 레이블로 붙는다. 시나리오는 IPCC SSP(현재 정책 SSP2-4.5 · 파리협약 2 °C SSP1-2.6 · 1.5 °C 탄소중립 SSP1-1.9) 또는 [직접 설계](전력 구성·전기차·탄소 포집·산림·기타 감축 레버). 인간활동 지구를 크게 보고 [자연만 있는 지구 보기]로 배출 0 지구와 바꿔 본다. 기록 서랍(CSV). 모든 수치 옆 ⓘ에 출처 |
| **1인칭 탐험** | 1인칭 시점으로 걸어다니며 직접 측정 |

## 1인칭 탐험 모드 조작법

시작 화면에서 **"1인칭 탐험"**으로 들어갑니다 (`MiniEarth.html`·소스 실행 모두 같음).
처음 들어오면 안내 3장(이동 → 측정 → 시간·행동)이 뜹니다. 화면을 클릭하면 마우스로 시점을 조작할 수 있고, **ESC**를 누르면 마우스가 풀립니다.
**키보드·마우스 전용입니다 — 태블릿 터치는 지원하지 않습니다.**

| 키 | 동작 |
|---|---|
| `W` `A` `S` `D` · `Shift` · `Space` | 이동 · 달리기 · 점프/헤엄 |
| 마우스 · 좌클릭 | 시점 · 든 도구로 측정 |
| `1`~`4` | 도구 (온도계 · pH미터 · CO₂센서 · 해수분석기) |
| `E` | 행동 지점·카페·분리배출장·시청과 상호작용 (준비 중) |
| `F` | 오른쪽 학습지 열기/닫기 (열린 상태에서는 `Esc` 도) — 과제 · 기록(평균·표준편차·횡단 조사·CSV) · 연도와 배출 경로 · 조작법 |
| `[` · `]` | 타임라인 정거장 이전/다음 (준비 중) |
| `M` · `R` | 미니맵 크기 · 출발점으로 |
| `H` | 조작법 (학습지 [과제] 맨 아래) |

값은 모두 그해 연평균입니다. 온도는 해수·빙하 표면·해양/녹지/도심 대기를 구분해서 재고, CO₂는 해양·녹지·도심이 다르게 나옵니다(**나무 바로 옆에서 재면 특히 낮게** 나옵니다).

## 문제 해결

| 증상 | 원인/해결 |
|---|---|
| **`index.html`을 더블클릭했더니** 화면이 새까맣고 텍스처가 안 보임 | 소스의 `index.html`은 서버가 있어야 동작합니다 (브라우저 보안 정책). 학생용으로 받은 **`MiniEarth.html`은 더블클릭이 맞습니다** — 둘을 헷갈리지 마세요. 소스로 보려면 아래 "개발용"처럼 `run_server.bat`을 켜고 `http://127.0.0.1:8000`으로 접속하세요 |
| **태블릿에서 1인칭 탐험이 안 움직임** | 1인칭 탐험은 **키보드와 마우스 전용**입니다(WASD 이동 + 마우스 시점). 터치 조작은 지원하지 않습니다. 태블릿에서는 "현재 실태"·"미래 예측" 화면만 쓰세요 |

## 개발용: 소스에서 직접 실행하기

코드를 고치며 확인할 때는 작은 개발 서버를 씁니다 (파이썬 설치 필요). 배포는 단일 HTML뿐입니다.

1. **`setup.bat`** 더블클릭 — 가상환경 생성 + 라이브러리(fastapi·uvicorn) 설치, 완료되면 바탕화면에 바로가기 생성
2. **`run_server.bat`** 더블클릭 (또는 바탕화면 바로가기) — `server.py`(정적 파일 서버) 실행 후 `http://127.0.0.1:8000`
3. 코드를 바꿨다면 **`build_html.bat`**으로 배포본 `dist/MiniEarth.html`(약 6.4 MB)을 다시 만듭니다. `dist/`는 `.gitignore` 대상이고, 배포는 GitHub Releases에 올립니다

### 화면 구성

| 경로 | 내용 |
|---|---|
| `/` | 시작 화면 (`select.html`) |
| `/dashboard?tab=current\|future` | 조감 모드 2개 탭 (`index.html` + `js/`) |
| `/firstperson/` | 1인칭 탐험 모드 (`firstperson/`) |

조감 모드와 1인칭 모드는 **같은 해수 화학(`js/earth-model.js`)을 공유**합니다. 해양 pH는 회귀식이 아니라 탄산 평형식(K₀·K₁·K₂ + 총알칼리도 일정)을 직접 풀어 구합니다(관측 35점 RMSE 0.008). 이 파일을 고치면 **두 모드에 동시에 반영**되므로, 한쪽만 바꿔서 두 화면이 다른 값을 내놓는 일이 없도록 여기서만 수정하세요.

조감 모드의 미래 예측·현재 실태 모형선은 **지구 시스템 엔진(`js/earth-system.js`)**을 씁니다. 배출량(`data/*.csv` → `js/earth-data.js`)을 4상자 탄소순환(대기·표층 바다·심층 바다·토양과 식생)에 넣어 시간에 따라 적분하고, 기온은 2층 에너지 균형(복사강제력 5.35·ln(CO₂/278))으로 계산합니다. NOAA 지구 평균 CO₂(1979~2024)를 RMSE 3.7 ppm으로 재현합니다(검증: `node tools/test_earth_system.js`). 화면의 모든 수치 출처는 `js/sources.js` 등록부에 있고 `docs/데이터출처.md` 로 정리됩니다. 1인칭 모드도 같은 엔진의 그해 값을 씁니다(`firstperson/fp-model.js`, 검증: `node tools/test_fp_model.js`). 지점 기온은 그해 연평균으로, 엔진 기온 편차에 IPCC AR6 육지·해양 증폭(1.46·0.81)을 곱해 냅니다.

- 참조 구현(파이썬): `tools/earth_system_ref/engine.py` — 식을 고칠 때는 여기부터 고치고 대조 테스트로 JS와 맞춥니다
- 대조 테스트: `node tools/test_earth_system.js` (파이썬+numpy 필요)
- 데이터를 고칠 때: `data/*.csv`를 고친 뒤 `python tools/gen_earth_data.py`로 `js/earth-data.js`를 다시 만듭니다

단일 HTML 빌드는 두 모드를 각각 iframe에 넣어 전역 스코프와 CSS를 분리합니다(두 모드가 같은 `earth-model.js`를 읽어 상수가 중복 선언되는 것을 피하기 위함). 자세한 내용은 `tools/build_single_html.py` 상단 주석에 있습니다.
